# サメの世界

> **サメが最初に海を泳いだのは、恐竜が生まれる2億年以上前だ。** ティラノサウルスが誕生し、栄え、絶滅した——その間もサメは泳ぎ続けた。そして今も泳いでいる。

## 概要

地球上で最も成功した捕食者の一つ、サメ。約4億5000万年前に登場した彼らは、5度の大量絶滅を生き延び、人類が文明を築くはるか以前から海の王者として君臨してきた。現在確認されているだけで553種が存在し、全長22センチの小型種から13〜14メートルの巨人まで、その多様性は圧倒的だ。「怖い」「危険」というイメージが先行するが、実態はまったく異なる。サメは精密な感覚器官を持つ進化の傑作であり、海の生態系を支える不可欠な存在であり、今まさに深刻な危機に瀕している生き物でもある。

## 基礎知識：まず知っておくべきこと

### 軟骨魚類という異色の存在

サメの骨格はすべて「軟骨」でできている。硬骨魚（マグロやタイなど）と根本的に異なる設計だ。軟骨は硬骨より軽く、しなやか。これが高速遊泳と急旋回を可能にする。骨がないかわりに、歯と皮膚の「皮歯（ひし）」は非常に硬い。皮歯は文字通り「皮膚にびっしり生えた歯」で、表面をなでると頭側から尾側は滑らかだが、逆向きにさわるとヤスリのようにザラザラする。この構造が水の乱流を抑え、静かかつ効率よく泳ぐ秘密だ。

### 歯はエスカレーター式で無限に生え変わる

サメの歯は生涯で何千本も生え変わる。歯の後ろには何列もの予備の歯が控えており、前列が抜けるとベルトコンベアのように次の列が前進してくる仕組みだ。ホホジロザメの場合、1本抜けると約8〜10日で新しい歯が機能し始める。人間の歯が一生に一度しか生え変わらないのに対し、サメは一生で2万本以上の歯を使い捨てる。

### 繁殖方法の「デパート」

サメの繁殖様式は驚くほど多彩だ。卵生・卵胎生・胎生の3方式すべてを持つ生き物は脊椎動物の中でも珍しい。さらに、オスがいなくても単為生殖で子孫を残せるメスがいることも判明している。2001年、アメリカの水族館でオスと一切接触のないウチワシュモクザメのメスが突然出産した事例が記録されており、DNA解析で父親の遺伝子が存在しないことが確認された。

## 驚きの事実 TOP5

1. **100万分の1ボルトを感知する「第六感」** — サメの吻（口先）周辺には「ロレンチーニ器官」と呼ばれる電気受容器が無数に存在する。この器官は1センチあたり1マイクロボルト（100万分の1ボルト）という極めて微弱な生体電流を感知できる。砂に埋まって完全に隠れたカレイさえ正確に見つけ出す実験結果が報告されている。心臓が動くだけで発生する微弱な電気信号が、サメにはバレてしまうのだ。

2. **恐竜より古く、進化がほぼ止まった生命体** — 最古のサメの祖先は約4億5000万年前のオルドビス紀に登場し、デボン紀（約4億年前）には現代のサメに近い形態が確立していた。つまりサメは、ティラノサウルス（約7000万年前）より3億年以上古い。5度の大量絶滅をすべて乗り越えた理由は、この「完成度の高さ」にある。

3. **世界最大の魚・ジンベエザメはプランクトンしか食べない** — 全長13〜14メートル、体重約20トンにもなるジンベエザメは、地球上で最大の魚類だ。しかしその食事は水中を漂う小さなプランクトンと小魚のみ。あれほど巨大な体を維持するために、1日あたり数百キログラムもの餌を口いっぱいに吸い込んで食べる。「最大」と「最凶」は必ずしも一致しない。

4. **世界で最も危険な場所はサメより「牛のいる牧場」** — サメによる人への死亡事故は年間平均わずか5〜10件（世界全体）。一方、牛による死亡は米国だけで年間約20件以上とされる。映画『ジョーズ』の影響で「人食いザメ」のイメージが定着しているが、実際にサメが人を好んで狙う証拠はない。多くの場合、誤認攻撃（亀やアザラシと間違えた）とされている。

5. **ホホジロザメは水族館で生きられない** — 世界中の水族館がホホジロザメの飼育に挑戦し、ほぼ全失敗している。沖縄美ら海水族館でも2016年に展示を試みたが、わずか3日で死亡した。理由は「口を開けたまま直線に泳ぎ続けること」が彼らの生命維持に不可欠だから。水槽の壁を認識できず衝突したり、直線を泳げずストレスで死亡する。世界で最も有名なサメは、水族館で見ることが原理的に不可能な生き物だ。

## 深掘り：専門家だけが知っていること

### 皮歯技術が航空工学と水着に革命をもたらした

サメの皮歯の構造は「リブレット（riblet）」と呼ばれ、V字型の微細な溝が水の乱流を整流する。この原理を応用したサメ肌水着（スピード社のファストスキン）は2000年代初頭の競泳界を席巻し、世界記録を次々に更新した。あまりにも高性能すぎて2009年に国際水泳連盟が規制・禁止するほどだった。現在はジェット機の機体表面、風力発電タービン、水中ドローンなど様々な分野でリブレット技術の応用研究が進んでいる。

### 南極海でサメが発見——「いるはずがない」場所で

2025年1月、研究者たちが南大洋のサウスシェトランド諸島付近に深海カメラを投入したところ、水深490メートル・水温約1℃という極限環境に体長3〜4メートルのサメが映り込んでいた。南極海は水温が低すぎてサメはほぼ生息できないとされてきた。どの種か、どこから来たのか、なぜそこにいるのか——謎は深まるばかりだ。この発見は、私たちがまだサメのことをほとんど知らないことを示している。

## 現代との接点

### 生態系の「要石」が崩壊しつつある

国際自然保護連合（IUCN）のレッドリストに登録されているサメは168種、全体の約30%にあたる。過剰漁獲・混獲・フィン・フィニング（ヒレだけ切り取って海に捨てる行為）・生息地破壊が主な原因だ。サメが減ると食物連鎖の上位が消え、中型魚が爆発的に増え、その結果として下層の生き物が激減する「栄養カスケード」が起きる。実際にサメが激減した海域では、エイが増殖してホタテやカキの養殖業に甚大な被害が出た事例が北米で報告されている。

### 環境DNA（eDNA）がサメ保護を変える

2025年の新技術として注目されているのが「環境DNA」を使ったサメの生息確認だ。サメが泳いだ海水には、皮膚や粘液由来のDNAが微量に残る。この水を採取・分析することで、サメの存在を傷つけることなく確認できる。絶滅危惧種であるシュモクザメの生息域調査にすでに応用が始まっており、従来の目視調査よりはるかに正確なデータが得られるようになってきた。

### 江戸時代から続く日本のサメ文化

気仙沼（宮城県）はフカヒレの国内生産量の約70%を占める世界有数のサメ漁港だ。フカヒレは江戸時代から清（中国）への輸出品として重宝され、乾燥フカヒレ・ナマコ・アワビの三品は「俵物三品」として金銀の代わりに決済された貿易品だった。また、日本神話にはサメを神として崇拝する文化が各地に残っており、出雲大社の神話「因幡の白兎」に登場するサメ（ワニ）も、古代日本ではサメを「ワニ」と呼んでいたことの名残だ。
